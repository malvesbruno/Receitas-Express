# 🍲 ReceitaExpress

- Um site de receitas desenvolvido em React com integração ao Firebase, permitindo que usuários encontrem, compartilhem e salvem receitas de forma prática e rápida.

## ✨ Funcionalidades

- 📖 Listagem de receitas

- 🔍 Busca de receitas por nome ou ingrediente

- ❤️ Favoritar receitas

- ➕ Adicionar novas receitas (com autenticação Firebase)

- ☁️ Armazenamento seguro no Firebase

## 🛠️ Tecnologias

- React

- Firebase (Firestore / Authentication)

- JavaScript / TypeScript (se aplicável)

- CSS / Tailwind / Styled Components (dependendo do que você usou)

## 📦 Como executar
```bash
Clone o repositório e instale as dependências:

git clone https://github.com/malvesbruno/Receitas-Express.git
cd receita-express
npm install
npm start
```
